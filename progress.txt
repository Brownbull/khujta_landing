## Codebase Patterns
- Static HTML/CSS projects don't require build/lint/test - just valid HTML/CSS
- Each persona mockup uses CSS variables for easy theming
- Semantic HTML structure with clear sections (nav, hero, services, agents, contact, footer)
- Use CSS custom properties (variables) for consistent theming
- Mobile-first responsive design with CSS Grid and Flexbox
